# veylqo-js

JavaScript SDK workspace for [Veylqo](https://github.com/jovrion/veylqo).

pnpm workspaces. The packages are empty scaffolds:

| Path | Name |
| --- | --- |
| `packages/core` | `@veylqo/core` |
| `packages/element` | `@veylqo/element` |
| `packages/cdn` | `@veylqo/cdn` |

`shorten`, `share`, and `<veylqo-share>` are not implemented yet.
Tracking stays in the service repo.

```bash
pnpm -r test
```
